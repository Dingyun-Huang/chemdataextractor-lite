# Bundled sentence model

`punkt_chem-1.0.pickle` is the chemistry-trained Punkt sentence tokenizer distributed by the MIT-licensed ChemDataExtractor project at `http://data.chemdataextractor.org/models/punkt_chem-1.0.pickle`. It is bundled here so sentence segmentation does not perform network access at runtime.
